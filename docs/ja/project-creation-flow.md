# プロジェクト作成の流れ

Ithyno を使った開発プロジェクトの作成とエージェント起動のシンプルなフローは以下の通りです。

1. **フォルダの初期化**:
   Ithyno で開発フォルダを開き、画面上の「Initialize」をクリックします。仕様書やタスクを管理するためのファイル群が自動的に作成されます。
2. **仕様とタスクの作成 (Propose)**:
   画面上の「New Change」から、作成したい機能の「仕様書」と「タスクのチェックリスト」を作成します。
3. **エージェントの自動実装 (Start)**:
   「Start」ボタンを押すと、AI エージェントが自動で専用の作業エリアを構築し、タスクのチェックリストに沿ってコードの実装・検証・レビューまでを自動的に進めます。
