# Project Creation Flow

The simple workflow for creating a project and starting agents in Ithyno is as follows:

1. **Initialize Folder**:
   Open your project folder in Ithyno and click "Initialize". This automatically sets up the basic files required to manage specifications and task lists.
2. **Draft Specs and Tasks (Propose)**:
   Click "New Change" on the dashboard to define your feature's specifications and build a task checklist.
3. **Automated AI Implementation (Start)**:
   Click "Start" to spawn AI agents. They will automatically set up an isolated workspace, write code, run tests, and perform reviews to complete the task checklist.
